# Java Boat Reservation System
This is an application made to digitalize a boat reservation system for a boat rental company

# Background
In our Software Engineering course we had a few simulated client cases.
This case was for a client that had a boat rental company and wanted to move from an old paper system to a digital one

# What it can do
* Show a day overview with all the reservations of that day in a calender view
* sort the day overview by boat type
* make a reservation for a boat rental
* add multiple boats per reservation
* put boats on broken status so they can't be selected to reserve
* show list of all the existing reservations
* sort the reservation list by name or number
* Edit an existing reservation
* Delete an existing reservation

# Tech Stack
This project was made in Java with the [Swing Framework](https://docs.oracle.com/en/java/javase/21/docs/api/java.desktop/javax/swing/package-summary.html) for the UI and uses [Maven](https://maven.apache.org/) as it's build system
